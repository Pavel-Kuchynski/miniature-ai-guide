# Python engineering style

## What it does

Guidance for writing and reviewing Python code in this repository. It covers
naming, module structure, logging, error handling, AWS integration, testing,
and documentation expectations.

## When to use it

Use this skill for any task that creates, modifies, or reviews `.py` files in
the repo, especially backend Lambda handlers, tests, and related README files.

## How to ask for it

Ask for "Python engineering style" when you want repository-specific guidance
or a review of Python code against the project's conventions.

## Prerequisites

Read `SKILL.md` first, then the relevant reference files under
`references/` for naming, logging, testing, and review details.
