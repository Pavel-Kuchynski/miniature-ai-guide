# Python Unit Testing

## What it does
This skill helps you write, review, and maintain Python unit tests for AWS Lambda code. It focuses on deterministic, isolated, fast tests that verify observable behavior instead of implementation details. The default framework is `pytest`.

## When to use it
Use it when writing tests for new Python Lambda code, adding regression coverage, fixing failing tests, or reviewing existing unit tests. It is also the right skill when testing input validation, error handling, fixtures, mocking, or AWS SDK boundaries.

## How to ask for it
Ask for this skill when you need unit tests for a Python Lambda, or when you want a test review against repository conventions. Example: "Write unit tests for this Lambda handler" or "Review these Python tests for correctness and maintainability."

## Prerequisites
Read the detailed guidance in `SKILL.md` and the reference files in `references/` before writing tests. Use `references/testing-rules.md` for general rules, `references/lambda-testing.md` for Lambda-specific rules, and `references/examples.md` for good and bad patterns.
